# QuantVault 📐

> Comprehensive Quantitative Aptitude Formula Vault, PYQ Pattern Trainer, and Revision Engine for CAT Aspirants.

QuantVault is a modern, high-performance web application designed to help CAT aspirants master Quantitative Aptitude through structured formula repositories, KaTeX-powered mathematical rendering, interactive PYQ pattern walkthroughs, trap alerts, and smart revision workflows.

---

## ✨ Features

- **📐 Formula Vault**: Clean, organized repository of formulas across Arithmetic, Algebra, Geometry, Modern Math, and Number Systems with native KaTeX rendering.
- **⚡ PYQ Pattern Hub**: Real exam question breakdowns with step-by-step logic, pattern categorization, and common traps.
- **⚠️ Trap Alerts & Common Mistakes**: Highlight dangerous pitfalls and trick answer choices that cost negative marks.
- **🔄 Quick Revision Engine**: Rapid-fire formula recalls and confidence-based active recall testing.
- **🗺️ Interactive Roadmap**: Structured learning milestones from foundational arithmetic to advanced modern math.
- **🧠 Confidence Selector & Progress Tracking**: Real-time progress indicators saving state across devices.
- **⌨️ Command Palette & Fast Navigation**: Keyboard-first interface with full modal shortcuts and instant search.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Math Rendering**: [KaTeX](https://katex.org/)
- **UI & Animations**: [Framer Motion](https://www.framer.com/motion/), [Radix UI](https://www.radix-ui.com/), [Lucide Icons](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/AxatVaghela/quantvault.git

# Navigate to project directory
cd quantvault

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
